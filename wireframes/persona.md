# Assistive Technology User Persona

## Profile
- **Name:** Raymond Tutu
- **Age:** 68
- **Occupation:** Retired Machinist
- **Tech Literacy:** Low to Moderate

## User Context and Needs
- Arthur lives with age-related visual impairment and early-stage arthritis in his hands. He accesses the internet using a desktop computer and relies heavily on high contrast text settings and keyboard navigation instead of a mouse.
- When visiting the clinic site, Arthur wants to quickly find available doctor appointments and check operating hours without getting lost in complicated drop-down menus or small buttons.

## Key Goals
- Easily check clinic opening times and walk-in triage availability
- Filter clinical services by specialty using keyboard shortcuts
- Complete the appointment request form with clear input labels and helpful error messages
- Navigate back home easily from any view using the main site title

## Technical Contraints
* Relies on keyboard navigation using Tab, Shift+Tab, Space, Enter and Escape
* Uses standard screen readers like NVDA to read out page sections and confirmation messages
